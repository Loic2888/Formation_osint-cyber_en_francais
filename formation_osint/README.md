# Open Source Intelligence (OSINT) Training

This directory contains advanced educational materials focused on Open Source Intelligence (OSINT) and digital investigation techniques. The modules provide practical frameworks for gathering and analyzing information from publicly available sources.

## Core Modules

- **Email Investigation (`adresse_mail.md`)**
  Techniques for verifying, tracing, and identifying the owners of email addresses using professional tools and search operators.
- **Username Analysis (`faire_parler_un_pseudo.md`)**
  Methodologies for tracking digital footprints across multiple social platforms and forums using pseudonyms.
- **Image Intelligence (IMINT) (`faire_parler_une_image.md`)**
  Analyzing metadata (EXIF data), reverse image searching, and geolocation techniques to extract information from visual content.
- **Phone Number Tracing (`numero_telephone.md`)**
  Strategies for identifying carriers, owner locations, and associated digital accounts using international phone numbers.

## Goal

The goal of this training is to equip investigators and security researchers with a robust, repeatable methodology for conducting digital footprinting and background investigations while maintaining operational security.
