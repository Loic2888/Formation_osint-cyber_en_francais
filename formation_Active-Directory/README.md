# Active Directory Training

> **Note:** This training material is entirely in French.

Welcome to the comprehensive training module on Active Directory. 

This course is designed to provide an in-depth understanding of Active Directory environments from an offensive and defensive security perspective. Throughout this training, you will learn to:

- **Identify Vulnerabilities:** Discover common and advanced flaws within Active Directory configurations and architecture.
- **Understand the Mechanics:** Grasp the underlying root causes and logic behind these vulnerabilities (e.g., Kerberos, NTLM, domain trusts).
- **Practical Exploitation:** Learn how to practically exploit these weaknesses to assess and test the security posture of an infrastructure, simulating real-world attack paths such as lateral movement, privilege escalation, and persistence mechanisms.

Whether you are an auditor or a security professional, this training aims to give you practical, hands-on knowledge to master Active Directory security.
