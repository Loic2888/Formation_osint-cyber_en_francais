# Dark Web Training

This directory contains specialized educational materials focused on navigating the Dark Web securely and maintaining high levels of operational security (OPSEC). These modules provide practical guides for setting up anonymous environments and conducting investigations on the Tor network.

## Core Modules

- **Secure Environment with Whonix (`tuto_best_environnement-securise_avec_whonix.md`)**
  A detailed guide on deploying a dual-VM architecture (Gateway & Workstation) using Whonix for maximum anonymity and protection against IP leaks.
- **Amnesic System with Tails OS (`tuto_environnement-sécurisé_avec_tails-os.md`)**
  Instructions for creating and using a Tails live USB, an amnesic system designed to leave no trace on the host computer.
- **First Steps on Tor (`tuto_premier-pas_sur_tor.md`)**
  A survival guide for the Tor network, including browser configuration (Safest mode) and a map of essential entry points (.onion sites).

## Goal

The goal of this training is to provide the technical foundation necessary for security researchers and OSINT analysts to explore the Dark Web safely, avoiding common pitfalls and ensuring their digital footprints remain untraceable.
