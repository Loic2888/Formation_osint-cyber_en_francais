# Cybersecurity Training Repository

Welcome to my cybersecurity training repository. This space is dedicated to sharing my knowledge through various educational materials and professional training courses I have developed.

The content here focuses on practical skills, methodologies, and technical deep-dives into different domains of information security, including OSINT, security audits, and more.

## Repository Contents

- [**Security Audit Training**](./formation_audit-de-securite/): A comprehensive course on cybersecurity auditing techniques and methodologies.
- [**OSINT Training**](./formation_osint/): Advanced techniques for Open Source Intelligence and digital investigations.
- [**Dark Web Training**](./formation_dark-web/): Specialized modules on secure navigation, OPSEC, and investigations on the Tor network.
- [**Active Directory Training**](./formation_Active-Directory/): Comprehensive training on Active Directory administration and security.

## Goal

The primary goal of this repository is to provide high-quality, professional educational resources in French to help fellow practitioners and students enhance their skills in the cybersecurity field.
