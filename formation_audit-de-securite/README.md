# Cybersecurity Audit Training

This directory contains the educational materials for a comprehensive 4-day training course on Cybersecurity Auditing. The course is designed to provide practitioners with the methodologies and practical skills necessary to perform professional security assessments.

## Modules Overview

- **Day 1: Fundamentals of Security Auditing**
  Introductory concepts, legal frameworks, and audit preparation.
- **Day 2: Technical Assessment Methodologies**
  Vulnerability scanning, manual testing techniques, and infrastructure auditing.
- **Day 3: Application & Network Security**
  Focus on specific audit vectors for web applications and network configurations.
- **Day 4: Reporting and Remediation**
  Standardizing audit reports and managing post-audit security improvements.

## Case Study

In addition to the training modules, this folder includes a professional audit report template/example:
- `rapport-audit_yahoo.md`: A case study presenting a security audit conducted on Yahoo's environment.

## Goal

By the end of this training, participants should be able to conduct a full infrastructure audit, identify critical vulnerabilities, and produce professional-grade reports.
